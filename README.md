## Requirements and Setup

Ensure you have **Python 3.x** installed. The advanced assignments require specific external libraries for data analysis and visualization.

Install the required dependencies using:

```bash
pip install -r requirements.txt
```

**Key Libraries Used:**
- `numpy`
- `pandas`
- `matplotlib`
- `seaborn`

---

## Usage

To execute any assignment program, navigate to the repository root and run the script using the Python interpreter. 

**Example:**

```bash
python "Assignment 1/01_even_or_odd.py"
```

Output and generated plots (if any) will be saved in the `output/` directory within the respective assignment folder.
